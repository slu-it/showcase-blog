== Overview

The Blog Post API provides CRUD operations for managing blog posts.
All endpoints require authentication via OAuth2 JWT tokens.

=== HTTP Status Codes

The API uses the following HTTP status codes:

|===
| Status Code | Description

| `200 OK`
| The request was successful. Returned for GET and PATCH operations.

| `201 Created`
| A new resource was successfully created. Returned for POST operations.

| `204 No Content`
| The request was successful but there is no content to return. Returned for DELETE operations.

| `401 Unauthorized`
| The request lacks valid authentication credentials. A valid OAuth2 JWT token must be provided.

| `403 Forbidden`
| The authenticated user does not have the required role to access the resource. Endpoints that modify data require the `AUTHOR` role, while read-only endpoints require the `USER` role.

| `404 Not Found`
| The requested resource does not exist.
|===
